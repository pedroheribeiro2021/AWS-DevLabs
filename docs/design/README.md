# Visual identity

Decided (2026-09-18): a redrawn vector version of the Option 1 concept below, now shipped in `apps/web` (favicon + nav bar).

- `logo-icon.svg` — the shipped mark: Erlenmeyer flask + `< >` code brackets, flat, no gradients. Navy ink (`#16233E`) for light backgrounds, orange (`#FF6B1A`) as the single constant accent (right bracket + flask liquid).
- `logo-icon-on-dark.svg` — same mark with ink swapped to off-white (`#F3F0E7`) for dark surfaces. Not currently used anywhere in the app (the UI is light-only today) — kept for whenever a dark surface (nav, dark mode) exists.

## Superseded candidates

The two files below were the original AI-generated concept explorations (2026-09-16) that the final mark is based on. Kept for history, no longer the working assets.

- `logo-option-1-flat.png` — flask + `</>` mark, flat navy/orange, no gradients. This is the concept the shipped SVG redraws.
- `logo-option-2-glossy.png` — same concept, glossy/3D rendering with gradients and an "eye" shape framing it. Rejected: Planejamento.md (section 27) asks for a clean, technical look and calls out avoiding excessive gradients; the glossy "eye" framing also read as a confusing metaphor. Both were raw AI output with a "Made with AI" watermark, never suitable to ship as-is.
